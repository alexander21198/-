# Продвинутый блокнот для заметок

## О проекте

**Продвинутый блокнот для заметок** — информационная система для создания, хранения, редактирования, поиска и систематизации личных, учебных и рабочих заметок.

Проект разрабатывается на языке C++ с использованием объектно-ориентированного программирования в рамках дисциплины «Основы проектной деятельности».

## Цель проекта

Разработать приложение, которое позволит пользователю удобно управлять заметками, группировать их по категориям и тегам, быстро находить необходимую информацию и сохранять данные между запусками программы.

## Функциональные требования

### 1. Управление заметками
- Создание заметки с заголовком и текстом.
- Редактирование существующих заметок.
- Удаление заметок с подтверждением.
- Просмотр списка всех заметок.
- Просмотр подробной информации о заметке.
- Архивирование заметок без удаления.
- Отметка важных заметок.

### 2. Категории и теги
- Создание категорий.
- Редактирование категорий.
- Удаление категорий.
- Привязка заметок к категориям.
- Добавление и удаление тегов.
- Фильтрация заметок по категориям и тегам.

### 3. Поиск и сортировка
- Поиск заметок по заголовку.
- Поиск по содержимому заметок.
- Фильтрация по категориям.
- Фильтрация по тегам.
- Фильтрация по дате создания.
- Фильтрация по важности.
- Сортировка по дате создания.
- Сортировка по дате изменения.
- Сортировка по названию.

### 4. Статистика
- Подсчёт общего количества заметок.
- Подсчёт важных заметок.
- Подсчёт заметок по категориям.

### 5. Хранение данных
- Сохранение заметок во внешний файл.
- Автоматическая загрузка данных при запуске.
- Сохранение категорий и тегов.
- Проверка корректности данных.

Для первой версии допускается использование TXT, CSV, JSON или бинарного формата.

В дальнейшем возможно использование SQLite.

## Структура данных

### Заметка (Note)

Каждая заметка должна содержать:

| Поле | Описание |
|------|----------|
| id | Уникальный идентификатор |
| title | Заголовок заметки |
| content | Текст заметки |
| createdAt | Дата создания |
| updatedAt | Дата изменения |
| category | Категория |
| tags | Список тегов |
| isImportant | Признак важности |
| isArchived | Статус архивирования |
| description | Дополнительное примечание |

### Категория (Category)

Каждая категория содержит:
- Название.
- Краткое описание.

## Архитектура приложения

Приложение должно использовать объектно-ориентированный подход.

Рекомендуемые классы:

| Класс | Назначение |
|-------|------------|
| Note | Хранение данных заметки |
| Category | Работа с категориями |
| Tag | Представление тегов |
| Notebook | Управление коллекцией заметок |
| FileStorage | Сохранение и загрузка данных |
| SearchService | Поиск и фильтрация заметок |
| Menu | Взаимодействие с пользователем |

Код должен быть разделён на логические модули.

## Требования к интерфейсу

Первая версия приложения может использовать консольный интерфейс.

Пользователь должен иметь возможность:
- Выбирать действия через меню.
- Создавать и изменять заметки.
- Просматривать результаты операций.
- Продолжать работу без перезапуска программы.

Интерфейс и сообщения пользователю должны быть на русском языке.

В дальнейшем возможно добавление графического интерфейса.

## Требования к надёжности

Программа должна:
- Проверять обязательные поля заметок.
- Не допускать создания заметки с пустым заголовком или текстом.
- Обрабатывать обращения к несуществующим заметкам.
- Запрашивать подтверждение перед удалением.
- Сообщать, если поиск не дал результатов.
- Обрабатывать ошибки чтения и записи файлов.
- Сохранять данные после завершения работы.
- Восстанавливать данные при следующем запуске.
- Не завершаться аварийно при некорректном вводе.

## Производительность

Операции добавления, редактирования, поиска и фильтрации должны выполняться без заметной задержки при количестве до 1000 заметок.

## Технологии

- Язык программирования: C++.
- Парадигма: объектно-ориентированное программирование.
- Библиотеки: стандартная библиотека C++.
- Хранение данных: локальные файлы.
- Операционные системы: Windows и Linux.
